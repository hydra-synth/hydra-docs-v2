# Hola món!

Comença a escriure codi a Hydra! Per començar:

1. Ves a https://hydra.ojack.xyz.

2. Tanca la finestra superior clicant la `[x]` a la cantonada superior dreta.

3. Canvia alguns números.

4. Prem `ctrl+shift+enter` per executar el codi (o fes servir el botó de triangle a la cantonada superior dreta).

5. Diverteix-te! No hi ha una manera "incorrecta" de codificar a Hydra :]

Modifica els valors que apareixen a l’[editor web de Hydra](https://hydra.ojack.xyz/) en els exemples per veure què passa.
Els valors poden ser decimals; es recomana no fer servir valors molt grans dins dels parèntesis. Els números han d’anar **dins** dels parèntesis.
Tot codi de Hydra comença generant un senyal d’entrada i acaba amb un *buffer* de sortida. Afegir valors dins o després de `.out()` **no funcionarà**.

```javascript
osc(10, 0.1, 0.5).color(1, 0.895, 0.55).out()
```
